## 🎯 **Padrões de Confiança**

### **Alta Confiança (90-100%)**

- ✅ Match exato de alias
- ✅ Comandos padrão conhecidos
- ✅ Linguagem natural exata

### **Média Confiança (70-89%)**

- 🔍 Similaridade alta
- 🔍 Variações conhecidas
- 🔍 Comandos de voz limpos

### **Baixa Confiança (50-69%)**

- ⚠️ Similaridade moderada
- ⚠️ Comandos com ruído
- ⚠️ Linguagem natural vaga

### **Rejeitado (<50%)**

- ❌ Similaridade muito baixa
- ❌ Comandos irreconhecíveis
- ❌ Spam ou texto sem sentido

```json
  "voice_settings": {
    "enabled": true,

  }
}
```

## 🎯 **Dicas de Uso**

### **Para Usuários**

- 🎤 **Use comandos de voz** para uma experiência mais natural
- 💬 **Seja específico** para melhor reconhecimento
- 🔄 **Use sinônimos** se um comando não funcionar
- 📱 **Siga as sugestões** quando o comando não for reconhecido

### **Para Desenvolvedores**

- 🔧 **Configure aliases** para maior flexibilidade
- 🎤 **Habilite voz** para melhor UX
- 📊 **Monitore métricas** de uso e confiança
- 🔄 **Atualize comandos** baseado no feedback dos usuários

## 🗄️ **Scripts SQL para Inserção dos Comandos**

### **📋 Estrutura da Tabela**

```sql
-- Tabela de comandos do Telegram
CREATE TABLE telegram_commands (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    command_id VARCHAR(255) UNIQUE NOT NULL,
    aliases JSON NOT NULL,
    description TEXT NOT NULL,
    action_handler VARCHAR(255) NOT NULL,
    action_method VARCHAR(255) NOT NULL,
    action_parameters JSON NULL,
    permissions JSON NOT NULL DEFAULT '["all"]',
    category VARCHAR(255) NOT NULL DEFAULT 'general',
    voice_settings JSON NULL,
    natural_language JSON NULL,
    fallback JSON NULL,
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    priority INTEGER NOT NULL DEFAULT 1,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,

    INDEX idx_category_active (category, is_active),
    INDEX idx_command_active (command_id, is_active),
    INDEX idx_priority (priority)
);
```

### **🔍 Verificar Comandos Inseridos**

```sql
-- Verificar todos os comandos ativos
SELECT
    command_id,
    aliases,
    category,
    priority,
    is_active
FROM telegram_commands
WHERE is_active = TRUE
ORDER BY priority, command_id;

-- Verificar comandos por categoria
SELECT
    category,
    COUNT(*) as total_commands
FROM telegram_commands
WHERE is_active = TRUE
GROUP BY category
ORDER BY total_commands DESC;

-- Verificar configurações de voz
SELECT
    command_id,
    JSON_EXTRACT(voice_settings, '$.enabled') as voice_enabled,
    JSON_EXTRACT(voice_settings, '$.priority') as voice_priority,
    JSON_EXTRACT(voice_settings, '$.language') as supported_languages
FROM telegram_commands
WHERE JSON_EXTRACT(voice_settings, '$.enabled') = TRUE
ORDER BY voice_priority;
```

### **📝 Notas Importantes**

1. **Escape de Barras**: No JSON, as barras invertidas devem ser escapadas (`\\`)
2. **Permissões**: Use `["all"]` para comandos públicos ou arrays específicos para restrições
3. **Prioridades**: Comandos com prioridade menor (1) são processados primeiro
4. **Categorias**: Organize comandos por funcionalidade para melhor manutenção
5. **Fallbacks**: Configure mensagens e sugestões úteis para melhor UX
